Component documentation for **Sunim**. One page per component, written by the 📄 doc-generator
once a component reaches `Completed` on the board.

## How a component gets here

```
To-do → Ready for Testing → To be fixed / Fixing / Fixed → To be deployed → Completed
```

Nothing on this site is written by hand from memory: props and states come from the component's
code and stories, purpose comes from its Figma node description, and a page is only written once
the component is live in production.
